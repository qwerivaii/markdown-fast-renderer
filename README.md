A dependency-free drop-in for marked 18.1.3: `parse(markdown)` returns exactly the HTML marked renders with its default options, and `main.ts` reads every case from `/input/cases.json` and writes the rendered HTML to `/output/html.json`.

## Run it

```sh
node main.ts
```
